# Privacy Policy

**Big Cat Newspaper Workflow**  
Last updated: October 26, 2026

## Overview

Big Cat Newspaper Workflow is a personal software application that automates newspaper processing, PDF generation, and delivery through Google Drive.

This privacy policy explains how the application accesses, uses, and manages Google account data.

## Information We Access

The application uses Google OAuth 2.0 to obtain authorized access to Google Drive.

It accesses Google Drive only to perform functions necessary for newspaper delivery, including:

- Uploading generated newspaper PDF files.
- Creating links to uploaded files.
- Managing files created by the application.
- Deleting older files according to the configured retention policy.

## How Information Is Used

Google Drive access is used exclusively to support the application's newspaper processing and delivery functions.

The application does not use Google account information for advertising, profiling, or marketing.

## Data Storage and Retention

Generated newspaper files are stored in the user's Google Drive account.

The application supports automatic deletion of uploaded files after a configurable retention period, currently set to 60 days.

OAuth credentials and authorization tokens are used to authenticate Google Drive requests.

## Data Sharing

The application does not sell personal information.

Generated PDF links may be shared with the email recipients configured by the user.

Google account data is not shared with third parties for advertising or marketing purposes.

## Data Security

The application uses Google's OAuth 2.0 authorization mechanism and HTTPS connections to communicate with Google services.

Users may revoke the application's Google account access through their Google Account security settings.

## User Control

Users retain control over their Google Drive files and may delete uploaded documents or revoke application access at any time.

## Changes to This Policy

This privacy policy may be updated to reflect changes in application functionality or Google API requirements.
